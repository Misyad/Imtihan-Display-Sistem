# 06A-visual-language-specification.md

# Imtihan Display System
## Visual Language Specification

Version : 3.0

---

# Purpose

Dokumen ini menerjemahkan referensi visual utama menjadi aturan desain yang dapat diimplementasikan secara konsisten.

Tujuannya bukan meniru gambar sebagai gambar.

Tetapi membangun bahasa visual yang memiliki karakter identik.

---

# Visual DNA

Aplikasi memiliki lima DNA utama.

1.
Islamic Architecture

↓

2.
Royal Ceremony

↓

3.
Formal Institution

↓

4.
Premium Heritage

↓

5.
Modern Software

Semua desain harus mengandung lima unsur tersebut.

---

# Overall Composition

Layout selalu simetris.

```

                HEADER

────────────────────────────────

          CONTENT AREA

────────────────────────────────

                FOOTER

```

Komposisi horizontal selalu menjadi fokus.

---

# Symmetry

Seluruh halaman menggunakan simetri.

Logo selalu center.

Header selalu center.

Divider selalu center.

Judul utama selalu center.

Tidak menggunakan layout acak.

---

# Visual Weight

Bobot visual dibagi menjadi:

Header

25%

Content

65%

Footer

10%

Header harus cukup besar untuk membangun identitas.

Namun tidak mendominasi konten.

---

# Header Architecture

Header terdiri dari tiga layer.

Layer 1

Background Cream

↓

Layer 2

Gold Ornament

↓

Layer 3

Identity

Logo

Kaligrafi

Nama Sistem

---

# Decorative Arch

Lengkungan menjadi identitas utama.

Karakter:

Lebar

Simetris

Elegan

Tidak terlalu tinggi

Radius besar

---

# Border System

Border mengelilingi seluruh halaman.

Tidak hanya card.

Tetapi aplikasi.

Border terdiri dari:

Top Border

↓

Side Border

↓

Bottom Border

↓

Corner Ornament

---

# Corner Ornament

Corner harus:

Simetris

Identik

Menghadap ke dalam

Menggunakan SVG

Tidak menggunakan PNG.

---

# Divider System

Divider digunakan untuk:

Header

Section

Dialog

Card

Footer

Divider selalu tipis.

Menggunakan aksen emas.

---

# Ornament Density

Kepadatan ornamen maksimal:

Header

100%

Footer

70%

Sidebar

20%

Card

15%

Dialog

15%

Content

0%

---

# Sacred Zone

Area tengah adalah area suci.

Tidak boleh terdapat:

Pattern tebal

Ornamen

Frame tambahan

Efek glow

Area ini hanya untuk informasi.

---

# Geometry Language

Menggunakan:

Bintang delapan

Hexagon

Lingkaran

Lengkungan

Segi delapan

Arabesque

Tidak menggunakan bentuk organik bebas.

---

# Frame Philosophy

Frame bukan dekorasi.

Frame adalah identitas.

Frame harus selalu terlihat.

---

# Surface Language

Surface menggunakan tiga tingkat.

Primary Surface

Cream

Secondary Surface

Soft Cream

Accent Surface

Emerald

Tidak menggunakan banyak warna.

---

# Depth

Depth dibangun melalui:

Border

Shadow ringan

Layer

Spacing

Bukan blur.

# Decorative Priority

4.

Ornamen

# Pattern Rules

Pattern hanya berada pada background.

Tidak pernah berada:

di Button

di Table

di Form

di Dialog

---

# Gold Usage

Emas digunakan untuk:

Frame

Divider

Highlight

Button Primary

Heading

Tidak digunakan sebagai background penuh.

---

# Emerald Usage

Emerald digunakan sebagai:

Background utama

Sidebar

Display

Interactive Board

OBS

---

# Cream Usage

Cream digunakan sebagai:

Panel

Header

Input

Table Header

Dialog

# Density

---

# Motion Philosophy

Semua animasi harus terasa seperti:

Pintu terbuka.

Kain bergerak.

Bukan game.

---

# Hover

Hover tidak mengubah layout.

Hover hanya:

Border

Elevation

Shadow

Brightness

---

# Focus

Focus menggunakan:

Gold Outline

2px

---

# Visual Contrast

Kontras dibangun menggunakan:

Cream

Emerald

Gold

Bukan menggunakan warna mencolok.

---

# Icon Philosophy

Icon mengikuti geometri yang sama.

Rounded.

Simple.

Elegant.

---

# Illustration Philosophy

Ilustrasi hanya mendukung.

Tidak menjadi pusat perhatian.

---

# Photography

Foto menggunakan:

Soft Shadow

Gold Border

Rounded XL

---

# Error State

Merah digunakan seminimal mungkin.

Tidak mendominasi halaman.

---

# Success State

Hijau yang lebih terang.

Tetap harmonis dengan emerald utama.

---

# Loading State

Loading menggunakan:

Logo

Progress

Spinner sederhana

Tidak menggunakan animasi berlebihan.

---

# Decorative Limits

Tidak diperbolehkan:

Glow

Glassmorphism

Cyber Effect

Neon

Heavy Gradient

Random Shape

Floating Object

---

# Responsive Philosophy

Pada layar kecil.

Frame tetap dipertahankan.

Hanya skalanya yang berubah.

Ornamen tidak boleh dihapus.

---

# SVG Principles

Semua ornamen dibuat dalam SVG.

Setiap elemen dapat diskalakan.

Tidak menggunakan bitmap.

---

# Design Consistency Checklist

Sebelum halaman dirilis, pastikan:

✓ Frame terlihat.

✓ Header konsisten.

✓ Divider sesuai standar.

✓ Ornament tidak mengganggu.

✓ Konten menjadi fokus.

✓ Whitespace cukup.

✓ Warna sesuai token.

✓ Tipografi sesuai hirarki.

✓ Layout simetris.

✓ Motion halus.

---

# Final Principle

Visual aplikasi harus dapat dikenali bahkan tanpa logo.

Jika seluruh logo dihapus, pengguna tetap harus mengetahui bahwa halaman tersebut merupakan bagian dari Imtihan Display System hanya dari frame, warna, proporsi, dan bahasa visualnya.
